# Pixiekat's Dotfiles

Just my general dotfiles for personal use; feel free to clone and modify as you wish.

## Inside

*`.cache\oh-my-posh\themes`*:

Custom oh-my-posh themes, which get synced to `~/.cache/oh-my-posh/themes`.

`iranian-solidarity.omp.json` is a theme based on `free-ukraine.omp.json` to signify opposition to the
[2026 US launched war with Iran](https://en.wikipedia.org/wiki/2026_Iran_war).
